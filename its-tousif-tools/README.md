## Features
- 60fps animations (transform & opacity only)
- Stagger fade-up, parallax blobs, magnetic buttons
- Drag & Drop upload with bounce icon
- Fully responsive (1280px max-width)
- Lucide SVG icons only (stroke 1.75)
- SEO: unique title/desc per page, canonical, OG, Twitter, JSON-LD (WebSite + SoftwareApplication)
- Working tools: Canvas DPI logic, jsPDF+html2canvas, Chart.js WhatsApp parser
- Privacy copy: "Your files are processed securely in your browser and never uploaded."
